    WIKILens is a cross-lingual bias detection tool for Wikipedia editors. It compares the same article across two language editions and scores each text chunk on four dimensions of potential bias: ideology, sentiment, framing, and omission.

    To begin, enter a Wikipedia article URL and select a language pair in the panel on the right, then click Analyze article. The analysis pipeline fetches both language editions, aligns their content, and uses a large language model to score each aligned chunk.

    Note: Analysis may take several minutes depending on article length and language pair. Results are generated fresh for each request.

    Score interpretation

    DimensionRangeInterpretation
    Ideology−1.0 to +1.0Negative = left-leaning; Positive = right-leaning; 0 = neutral
    Sentiment−1.0 to +1.0Negative = unfavorable tone; Positive = favorable tone
    Framing−1.0 to +1.0Negative = negative framing; Positive = positive framing
    Omission0 to 1.00 = nothing omitted; 1 = all baseline content omitted

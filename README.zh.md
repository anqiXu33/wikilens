# WikiLens

**维基百科跨语言偏见分析工具。** 把同一个词条的两个语言版本放在一起，对齐讲同一件事的段落，看看每个版本漏掉了什么、又是怎么说的。

[English](README.md)

![社会信用体系，英文版与中文版：汇总卡片与分章节框架分数](docs/images/social_credit_results.png)

## 它做什么

给定一个词条和一组语言（比如英文和中文），WikiLens 会：

1. **抓取**两个版本并按段落切分
2. **对齐**：用 LaBSE 向量取相似度前 10 的候选，再让大模型判断哪些候选讲的是同一件事
3. **打分**：对每段用大模型评估意识形态、情感、框架倾向（−1 到 +1），并根据对齐结果计算**遗漏分数**（0 到 1）
4. **展示**：网页界面里有分章节的偏见图、差异最大的段落、以及两个方向的内容缺口

大模型后端可换：IBM watsonx、任何 OpenAI 兼容接口（OpenRouter、Groq 等）或本地 Ollama。参考配置是 Llama 3.3 70B。

## 对齐有多准

遗漏分数完全依赖对齐，所以我对对齐做了人工评估：标注了《华为》和《社会信用体系》两篇的 54 段中文，逐段判断哪些英文段落讲的是同一件事。

| 对齐方法 | 精确率 | 召回率 | F1 |
|---|---|---|---|
| 段级相似度，原阈值 | 0.15 | 0.29 | 0.20 |
| 段级相似度，调优阈值 | 0.59 | 0.36 | 0.45 |
| 句级相似度 | 0.61 | 0.43 | 0.50 |
| **前 10 候选 + 大模型重排（英中默认）** | **0.62** | **0.69** | **0.65** |

原方法配出的对里 85% 是错的。调阈值有帮助，但三分之一的正确对应根本不在相似度前 3 名，因为中文一段常常写了好几件事，英文却分散在几个短段里。让大模型读前 10 个候选能找回大部分。完整数据见 `docs/alignment_experiments.md`。

**局限**：54 段、两篇文章、一位标注者、一个语言对；默认方法 F1 的 95% 置信区间约 0.54 到 0.75，两篇文章的最优阈值不一致；标注的候选来自原方法，评估对它有利。偏见打分本身尚未做人工验证。

## 它发现了什么

![内容缺口：中文版没有对应内容的英文段落](docs/images/social_credit_coverage_gaps.png)

- **同一家公司，侧重不同。** 中文《华为》主要写公司内部：早期交换机、管理文化、员工待遇、子公司；英文主要写外部：制裁、安全指控、5G 禁令。
- **同一份报道，相反的用法。** 中文《社会信用体系》在负面评价里引用 2015 年荷兰媒体的报道；英文把同一份报道放在「误解」一节，当作「全国统一信用分」这个误解的源头。
- **同一事实，相反的框架。** 两边都写了华为设备便宜、部署广；中文视为竞争优势，英文一处把它写成安全漏洞影响面大的原因。
- **两个方向都有缺口。** 瑞典的 5G 禁令、华为不上市的原因只有中文写了；社会信用体系 1999 到 2007 年的早期政策史只有英文写了。
- **单纯的漂移。** 多处年份相差一年，有一节中文几乎是英文的直译，2025 年底的新规只有中文收录。

中文维基百科的编辑来自中国大陆、台湾、香港和海外，这些差异反映的是编辑社区，不代表任何官方立场。

## 安装与运行

```bash
git clone https://github.com/anqiXu33/wikilens
cd wikilens
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 配置大模型后端，见英文版 README
```

```bash
python -m wikilens run --title "Huawei" --pair en-zh   # 完整流程
python -m wikilens serve --offline                      # 浏览已保存的结果，不联网、不需要 key
```
